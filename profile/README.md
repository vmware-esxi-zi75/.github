## Fast Hypervisor Brief
What is VMware ESXi? A type-1 hypervisor that installs directly onto server hardware.  
Who uses it? Datacenter administrators and businesses running production workloads.  
Does it need an OS? No, ESXi is the operating system and runs bare metal.  
How are VMs managed? Through a web client or vCenter for larger fleets.  

## Hypervisor Overview
VMware ESXi is a purpose-built bare-metal hypervisor designed to consolidate many workloads onto a single physical server. Because it installs directly on the hardware, there is no underlying general-purpose operating system to slow things down, giving virtual machines near-native performance and predictable behavior.

The small footprint of ESXi reduces the attack surface and simplifies maintenance. Its hardened architecture is engineered for continuous operation, making it a cornerstone of countless datacenters where uptime and reliability are non-negotiable requirements.

Administrators interact with ESXi through an intuitive host web client for single servers, or through vCenter Server when managing clusters. This layered approach scales from a single lab box to sprawling enterprise environments with thousands of virtual machines.

## Getting Started Playbook
Prepare compatible server hardware and download the ESXi installer image. Boot the server from the installer, accept the license, select the target disk, and set a root password. Within minutes the hypervisor is installed and reports a management IP address on its console screen.

Point a browser at that address to reach the host web client, where you can create datastores, configure networking, and build your first virtual machines. For multi-host environments, deploy vCenter Server to unlock clustering, live migration, and centralized policy management across the fleet.
